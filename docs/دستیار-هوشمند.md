# راهنمای نصب دستیار هوشمند

این سند راهنمای نصب و راه‌اندازی **دستیار هوشمند** در بازوی مواد تاندیش (بله) است. نسخهٔ PDF همین محتوا در `docs/راهنمای_نصب_دستیار_هوشمند.pdf` قرار دارد.

## ۱. معرفی و محدودیت

**دستیار هوشمند** یک گفتگوی محلی داخل ربات بله است که فقط دربارهٔ **گزارش‌ها و اعداد گزارش‌محور** پاسخ می‌دهد:

- خلاصه مصرف ماهیانه، ورودی انبار، مصرف روزانه/بازه‌ای
- موجودی و مواد بحرانی، مواد مازاد، پیش‌بینی، پیشنهاد درخواست
- فعالیت کاربران و مفاهیم PDF کامل تحلیل

### محدودیت‌های مهم

| مورد | توضیح |
|------|--------|
| دامنه | **فقط گزارش‌ها** — آپلود، ویرایش موجودی، درخواست مواد، مدیریت کاربر و تنظیمات را انجام نمی‌دهد |
| اجرا | مدل روی **همین سرور** با Ollama (یا سازگار) — **بدون API ابری** |
| نقش‌ها | همه نقش‌ها به‌جز **تکنسین** |
| قطعی بودن | اگر Ollama خاموش باشد، ربات کرش نمی‌کند؛ پیام فارسی «دستیار محلی در دسترس نیست…» نشان داده می‌شود |

## ۲. پیش‌نیاز سخت‌افزار و نرم‌افزار

| مورد | پیشنهاد |
|------|---------|
| سیستم‌عامل | لینوکس (Ubuntu/Debian یا سازگار) |
| Python | ۳٫۱۰ یا بالاتر (برای خود ربات) |
| RAM | حداقل **۴ گیگابایت** برای مدل `qwen2.5:3b`؛ با **۸ گیگابایت+** راحت‌تر |
| CPU | چند هسته کافی است؛ GPU اختیاری |
| فضای دیسک | چند گیگابایت برای مدل (مدل ۳B معمولاً حدود ۲ گیگابایت) |
| شبکه | نصب اولیه Ollama و `ollama pull` نیاز به اینترنت دارد؛ پس از آن کار محلی است |

مدل پیش‌فرض ربات: `qwen2.5:3b`. اگر RAM کم است از `qwen2.5:1.5b` استفاده کنید.

## ۳. نصب همراه ربات با `install.sh`

در ترمینال واقعی (TTY):

```bash
cd special-materials-robot-project
bash install.sh
```

ویزارد فارسی می‌پرسد:

> دستیار هوشمند را هم نصب کنم؟ (Y/n)

با پاسخ پیش‌فرض **بله** (Enter یا `Y`):

1. در صورت نبود، **Ollama** نصب می‌شود
2. مدل پیش‌فرض (`qwen2.5:3b` یا مقدار `OLLAMA_MODEL`) با `ollama pull` کشیده می‌شود
3. متغیرهای `OLLAMA_*` در `.env` نوشته/به‌روز می‌شوند

### پرچم‌های غیرتعاملی

| پرچم | معنی |
|------|------|
| `--with-assistant` | بدون پرسش، Ollama + مدل + `.env` را نصب/تنظیم کن |
| `--no-assistant` | دستیار را رد کن (Ollama نصب نشود) |

مثال:

```bash
bash install.sh --with-assistant --systemd --start
bash install.sh --no-assistant
```

جزئیات بیشتر: [DEPLOY.md](../DEPLOY.md).

## ۴. نصب دستی Ollama و مدل

اگر `install.sh` را با `--no-assistant` زده‌اید یا می‌خواهید دستی نصب کنید:

```bash
# نصب Ollama (Linux)
curl -fsSL https://ollama.com/install.sh | sh

# اگر سرویس بالا نیست:
ollama serve

# کشیدن مدل پیش‌فرض
ollama pull qwen2.5:3b

# یا مدل سبک‌تر برای RAM کم:
ollama pull qwen2.5:1.5b
```

سایر گزینه‌ها: `llama3.2:3b`, `phi3:mini`.

## ۵. تنظیم `.env`

در ریشهٔ پروژه (کنار `main.py`):

```bash
OLLAMA_BASE_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen2.5:3b
OLLAMA_TIMEOUT=60
```

- اگر این خطوط نباشند، همین مقادیر پیش‌فرض در کد استفاده می‌شوند.
- `OLLAMA_BASE_URL` باید به سرویس محلی اشاره کند؛ به سرویس ابری وصل نکنید.
- نمونهٔ کامل: `.env.example`.

## ۶. راه‌اندازی و تست

### تأیید Ollama

```bash
ollama list
```

باید مدل (مثلاً `qwen2.5:3b`) در فهرست باشد.

تست API محلی:

```bash
curl -s http://127.0.0.1:11434/api/tags
# یا یک چت کوتاه:
curl -s http://127.0.0.1:11434/api/chat -d '{
  "model": "qwen2.5:3b",
  "messages": [{"role": "user", "content": "سلام"}],
  "stream": false
}'
```

### روشن کردن ربات

```bash
source .venv/bin/activate
python main.py
# یا:
bash install.sh --systemd --start
```

ربات و Ollama باید **هم‌زمان** روی همان ماشین در دسترس باشند.

## ۷. استفاده در بله

1. در بله به بازو `/start` بزنید.
2. منوی **«گزارش‌ها / تحلیل تاندیش»** را باز کنید.
3. دکمهٔ **«🤖 دستیار هوشمند»** را بزنید.
4. سؤال خود را دربارهٔ گزارش‌ها بنویسید.
5. برای خروج: **«پایان گفتگو»** یا بازگشت به تحلیل / منوی اصلی.

**نقش تکنسین** به این منو دسترسی ندارد.

امنیت: هیچ درخواست LLM به ابر ارسال نمی‌شود؛ فقط HTTP محلی به Ollama روی سرور شما.

## ۸. رفع اشکال

| مشکل | کار پیشنهادی |
|------|----------------|
| پیام «دستیار محلی در دسترس نیست؛ Ollama را روی سرور بررسی کنید.» | `systemctl status ollama` یا `ollama serve`؛ پورت `11434`؛ `OLLAMA_BASE_URL` |
| مدل در `ollama list` نیست | `ollama pull` مطابق `OLLAMA_MODEL` |
| پاسخ خیلی کند | مدل کوچک‌تر (`1.5b`)، افزایش `OLLAMA_TIMEOUT`، RAM/CPU بیشتر |
| تکنسین دکمه را نمی‌بیند | طبق طراحی؛ نقش‌های دیگر را استفاده کنید |
| دو نمونه ربات با یک توکن | فقط یک polling؛ نمونهٔ اضافه را خاموش کنید |

لاگ ربات (systemd): `journalctl -u nasoz-bot -f`

## ۹. به‌روزرسانی

### به‌روزرسانی کد ربات

```bash
bash install.sh --update
```

### به‌روزرسانی / تعویض مدل

```bash
ollama pull qwen2.5:3b
# یا مدل جدید:
ollama pull qwen2.5:1.5b
```

سپس در `.env` مقدار `OLLAMA_MODEL` را عوض کنید و ربات را restart کنید:

```bash
sudo systemctl restart nasoz-bot
# یا Ctrl+C و دوباره python main.py
```

---

**خلاصه امنیتی:** دستیار هوشمند فقط گزارش‌محور است، روی سرور شما اجرا می‌شود، و به LLM ابری وابسته نیست.
